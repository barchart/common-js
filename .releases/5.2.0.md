**New Features**

* Added the configurable `AwsOptions` singleton with `useDefaultOptions()` and `setOptions()` functions for managing shared AWS SDK client configuration.

**Breaking Changes**

* Moved AWS client `region` and `endpoint` values from provider configuration to client options.
* Removed the unused AWS SDK v2 `apiVersion` configuration from AWS service providers.
* Moved the `DynamoProvider` `preferConsistentReads` option to the provider configuration argument.
