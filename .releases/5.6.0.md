**New Features**

* Added the `LambdaEventParser.getPathParameters` function to return all URL-decoded path parameters.
* Added the `UnitCode` enumeration, the `monthCodes` definitions, and the `unitCodeToBaseCode` function to the @barchart/common-market-js package (ported from the @barchart/marketdata-api-js package).
* Added the `formatPrice`, `formatDecimal`, `formatFraction`, and `formatForCmdtyView` functions to the @barchart/common-market-js package (ported from the @barchart/marketdata-api-js package).

**Bug Fixes**

* Corrected the `numberToString` function (in the @barchart/common-js package) to apply the thousands separator when rounding carries a value into the thousands (e.g. `numberToString(999.999, 2, ',')` now returns `1,000.00` instead of `1000.00`).
