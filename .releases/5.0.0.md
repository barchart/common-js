**Breaking Changes (common-js)**

* Removed the `common-js/network/RestProvider` class (and related classes).
* Removed the `Timezone.moment` property.
* Removed support for coercion of moment instances as `DataType.DAY` attributes in the `Schema` serialization framework.

**Breaking Changes (common-node-js)**

* Removed `common-node-js/sms/TwilioProvider` class.
* Removed `common-node-js/Environment` class.
* Removed the `common-node-js/data` query provider and result processor framework.

**New Features (common-js)**

* Added `is.regexp` for checking JavaScript `RegExp` instances.

**Bug Fixes (common-js)**

* Fixed `assert.argumentIsArray` validation for built-in item type constraints.
