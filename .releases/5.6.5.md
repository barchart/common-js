**Bug Fixes**

* Corrected failure of the `RateLimiter` to reject any pending actions on disposal.
* Corrected regression (5.6.3) that may cause the `RateLimiter` to generate an unhandled promise rejection on disposal (and potentially crash a Node.js process).
* Corrected regression (5.0.0) that caused the `numberToString` function to throw in some cases.
* Corrected regression (5.0.0) that caused the `WindowCounter.getAverage` function to return a stale value.
