**Bug Fixes**

* Corrected regression to the `promise.pipeline` function which failed to resolve the `input` parameter when promises are passed.
* Corrected issues with the `DynamoProvider.scan` and `DynamoProvider.query` functions that caused incomplete results to be erroneously returned in some cases (e.g. a subsequent page of results cannot be deserialized or fails with a non-retryable error). Now, in these cases, a rejected promise will be returned.
* Corrected failure of the `HttpProvider` to reject when a request fails before a response is received (instead of throwing an uncaught exception at the process level).

**Other**

* Removed hard-coded region fallback from `LambdaSecretsManager` and instead allow `AwsOptions` to manage the fallback.
* Removed hard-coded region fallback from `LambdaResponseGeneratorS3` and instead allow `AwsOptions` to manage the fallback.
