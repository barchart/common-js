**Breaking Changes**

* Removed the `LambdaValidator` class, which was deprecated in the previous major version.

**New Features**

* Added support for passing AWS SDK client configuration to AWS service providers.

**Technical Enhancements**

* Updated the [`date-fns`](https://www.npmjs.com/package/date-fns) package to the next major version.
* Switched the [`date-fns-tz`](https://www.npmjs.com/package/date-fns-tz) package to the [`@date-fns/tz`](https://www.npmjs.com/package/@date-fns/tz) package, which is the [officially supported package](https://blog.date-fns.org/v40-with-time-zone-support/) for timezone support in [`date-fns`](https://www.npmjs.com/package/date-fns).
* Removed the [`moment`](https://momentjs.com/) package which has been [deprecated](https://momentjs.com/docs/#/-project-status/) for some years.
* Removed the [`moment-timezone`](https://momentjs.com/timezone/) package, which has been [deprecated](https://momentjs.com/docs/#/-project-status/) for some years.
* Removed the [`@barchart/marketdata-api-js`](https://github.com/barchart/marketdata-api-js) package as a dependency (it is no longer used).
* Removed several development-only configuration files from the npm packages.
